# Calorie Tracker

A cross-platform mobile app for tracking daily calorie and nutrition intake, built with **React Native + Expo**. This was my bachelor's thesis (licență) project.

## Features
- Log meals and track daily calorie intake
- Food database with nutritional information
- Firebase / Firestore backend for data storage and sync
- Clean, mobile-first UI

## Tech stack
- React Native + Expo
- JavaScript
- Firebase (Firestore)

## Getting started
```bash
npm install
npx expo start
```
